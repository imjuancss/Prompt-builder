# 🚀 Landing Page Prompt & Style Studio

Un entorno de trabajo interactivo diseñado para planificar, configurar el estilo visual y estructurar **prompts de alto rendimiento** para la generación de Landing Pages de alta conversión utilizando modelos de Inteligencia Artificial (Gemini, ChatGPT, Claude, Cursor, v0).

---

## ✨ Características Principales

- **🎨 Configuración Estilística & Tipográfica:**
  - Selector interactivo de paletas de colores (Primario, Secundario, Acento, Fondo, Texto) con temas prediseñados.
  - Integración de catálogo de **Google Fonts** con combinaciones recomendadas para Títulos y Cuerpo.
  - **Previsualización en vivo en pantalla dividida (Split-View)** que actualiza en tiempo real los componentes UI al modificar estilos.

- **🧩 Generador Modular de Secciones:**
  - Estructuración paso a paso de landing pages (Hero, Features, Pricing, Testimonials, FAQ, CTA, etc.).
  - Configuración fina de variables de conversión (Propuesta de valor, Público objetivo, Beneficios clave, Call to Actions).

- **🤖 Generación Automática de Prompts para IA:**
  - Generación de **Prompts Globales** y específicos por sección listos para copiar y pegar en herramientas de generación de código por IA.
  - Incluye guía integrada de contexto e instrucciones del benchmark.

- **📜 Historial de Versiones & Snapshots:**
  - Guardado de versiones para comparar cambios e iteraciones visuales.
  - Gestión completa de proyectos (Creación, Duplicación, Edición y Eliminación segura).

- **💾 Persistencia Local:**
  - Almacenamiento automático en `localStorage` sin necesidad de configuraciones complejas de backend.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React 18 + TypeScript + Vite
- **Estilos:** Tailwind CSS
- **Componentes UI:** Radix UI / Shadcn UI
- **Iconos:** Lucide React
- **Animaciones:** Motion (`framer-motion` / `motion`)

---

## 🚀 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/landing-page-prompt-studio.git
   cd landing-page-prompt-studio
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Construir para producción:**
   ```bash
   npm run build
   ```
